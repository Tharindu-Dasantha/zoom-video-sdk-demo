# Design Review Handout

Use this checklist while reviewing each page at **desktop (~1440px)** and **mobile (~390px)** widths. For every page, check off each item or note an issue with a short description and (ideally) a screenshot.

## General checklist (apply to every page)

- [ ] No overlapping elements (text over images, buttons over text, etc.)
- [ ] Consistent spacing/padding between sections
- [ ] Text doesn't get cut off or overflow its container
- [ ] Buttons and inputs are aligned consistently
- [ ] Images/logos render at the correct size and aspect ratio
- [ ] No horizontal scrollbar on mobile
- [ ] Touch targets are large enough on mobile (buttons, links)
- [ ] Color contrast is readable (text vs. background)
- [ ] Loading/empty/error states look correct (if applicable)
